# Simulation-based R implementation of the methane genomic-evaluation workflow

This repository provides a simulation-based R implementation of the main analytical procedures described in the associated manuscript:

**Routine Genomic Evaluation of Mid-Infrared-Predicted Methane Emissions in Holstein Cattle: Validation and Implementation of Methane-Efficiency Breeding**

The code is provided to illustrate the statistical workflow without disclosing confidential animal-level phenotypic, pedigree, genomic, or official routine-evaluation data.

**Important:** the scripts use simulated data. Numerical results generated by these scripts are methodological examples and are **not expected to reproduce the empirical estimates, tables, or figures reported in the manuscript**.

## Repository contents

- `ch4_AGC_ME_indices_simulation_test.R` — main simulation and workflow-demonstration script.
- `quick_test_runner.R` — optional rapid software check using a reduced number of bootstrap replicates.
- `.gitignore` — prevents locally generated simulation outputs and R session files from being committed accidentally.

No empirical animal-level data are distributed in this repository.

## Analytical workflow demonstrated

The main R script demonstrates the following steps:

1. simulation of animal-level genomic estimated breeding values (GEBV) and genomic reliabilities;
2. selection of a high-reliability bull reference population;
3. adjustment of GEBV for birth-year genetic trends;
4. estimation of approximate genetic correlations (AGC);
5. bootstrap estimation of standard errors and 95% confidence intervals;
6. construction of methane-efficiency indices;
7. standardization of methane-efficiency indices to a mean of 100 and standard deviation of 10 in a reference group;
8. a simulated daughter-performance workflow check; and
9. simulation-based linear-regression (LR) validation of genomic predictions.

Install the required package in R with:

install.packages("data.table")

## Main script

### `ch4_AGC_ME_indices_simulation_test.R`

This is the main script. It generates simulated animal-level data and runs the complete demonstration workflow.

A fixed random seed is used to make the simulation reproducible.

### Full simulation run

The default run uses 1 000 bootstrap replicates:

```bash
Rscript ch4_AGC_ME_indices_simulation_test.R
```

The bootstrap count can also be specified explicitly:

```bash
B_AGC=1000 Rscript ch4_AGC_ME_indices_simulation_test.R
```

On Windows Command Prompt:

```bat
set B_AGC=1000
Rscript ch4_AGC_ME_indices_simulation_test.R
```

The script writes locally generated files to:

```text
CH4_simulation_test_results/
```

These generated outputs are intentionally excluded from the GitHub repository by `.gitignore`.

## Quick software check

### `quick_test_runner.R`

This optional helper script runs the main workflow with only 50 bootstrap replicates. Its purpose is to verify that the R environment, dependency, and full code path work correctly.

Run:

```bash
Rscript quick_test_runner.R
```

The quick test is **not** a full bootstrap analysis and its numerical output should not be interpreted as an empirical manuscript result.

## Genetic-trend adjustment

For each trait, the script calculates mean GEBV by sire birth year and fits a weighted quadratic regression:

```text
mean GEBV ~ birth year + birth year^2
```

The fitted birth-year trend is subtracted from each animal's GEBV to obtain trend-adjusted GEBV.

The simulation is designed to demonstrate the same type of trend-adjustment workflow described in the manuscript, rather than to reproduce the empirical trend estimates.

## Approximate genetic correlations

AGC is calculated from the correlation between GEBV vectors together with a reliability-based attenuation correction. Non-parametric bootstrap resampling of animals is used to estimate standard errors and percentile 95% confidence intervals.

### Correlation-bound diagnostic

AGC estimates are **not artificially truncated to the interval [-1, 1]**.

With an approximate attenuation correction, particularly when reliability values are simulated or approximated, an estimate may occasionally fall outside the theoretical correlation interval. Such values are retained and flagged by diagnostic variables rather than silently clipped.

This avoids artificially reducing bootstrap variability and prevents misleading results such as a standard error of zero caused by repeated truncation at ±1.

Values outside [-1, 1] in this simulation should therefore be interpreted as diagnostics of the approximation, not as biologically valid genetic correlations.

## Methane-efficiency indices

The script illustrates three definitions of methane efficiency using trend-adjusted GEBV:

- **MEP / RMEP** — methane efficiency relative to production traits (milk, fat, and protein yield);
- **MEF / RMEF** — methane efficiency relative to the functional economic index; and
- **MEG / RMEG** — methane efficiency relative to the global economic index.

For each definition, expected methane GEBV is predicted from the relevant breeding-goal traits or index.

Methane efficiency is calculated as:

```text
ME = expected trend-adjusted PCH4 - observed trend-adjusted PCH4
```

Thus, a larger ME value indicates lower methane emission than expected for the corresponding production or breeding-goal level.

The relative indices are standardized as:

```text
RME = 100 + 10 × (ME - reference mean) / reference SD
```

The simulated reference group therefore has a mean of 100 and a standard deviation of 10 by construction.

## Reliability of simulated methane-efficiency indices

The public simulation does **not** reproduce the official empirical index-reliability procedure.

To allow the AGC workflow to run end-to-end, the script creates clearly labelled simulation-only reliability proxies:

- `RMEP_GREL_PROXY`
- `RMEF_GREL_PROXY`
- `RMEG_GREL_PROXY`

These proxy values are derived from component-trait reliabilities and are used only for workflow demonstration.

They **must not be interpreted as the official RME reliabilities used in the empirical genomic evaluation**. An empirical application should replace them with the corresponding official index reliabilities.

## Simulated daughter-performance workflow

The daughter-performance section is a simulation-based workflow demonstration.

The simulated daughter methane outcome is generated from latent sire methane genetic merit plus sampling noise. It is **not generated directly from RMEP, RMEF, or RMEG**, avoiding direct circular construction of the outcome from the predictor being evaluated.

This module illustrates downstream regression and classification procedures only. It should not be interpreted as independent empirical validation.

The daughter analyses reported in the manuscript were based on the actual routine-evaluation data and are not reproduced by this public simulation.

## Linear-regression validation

The script illustrates LR validation by comparing simulated GEBV from partial and whole evaluations.

The reported statistics include:

- LR population accuracy;
- dispersion;
- level bias;
- correlation between partial- and whole-evaluation GEBV; and
- ratio of partial-to-whole population accuracies.

In the implementation, the ratio of accuracies is estimated as:

```text
cor(GEBV_partial, GEBV_whole)
```

The simulated LR statistics demonstrate the calculation procedure and are not intended to reproduce the numerical LR results reported in the manuscript.

## Relationship to the manuscript

This repository is intended to provide a transparent, simulation-based implementation of the analytical workflow while respecting confidentiality restrictions on the original routine-evaluation data.

The empirical estimates reported in the manuscript — including genetic parameters, approximate genetic correlations, methane-efficiency indices, daughter-performance results, and genomic-validation statistics — were obtained from the actual Walloon Holstein evaluation data.

Because the original phenotypic, pedigree, and genomic records are confidential, they are not included in this repository.

Accordingly, results generated by the public simulation scripts are not expected to match the empirical tables, figures, or numerical estimates in the manuscript.

## Data availability

The original phenotypic, pedigree, and genomic data used in the study are confidential routine-evaluation data owned by participating organizations and farmers. Access is subject to the relevant data-use agreements.

This repository therefore provides simulation-based R code that illustrates the analytical procedures without releasing confidential animal-level information.

## Reproducibility

The main simulation uses a fixed random seed (`20260606`). With the same R environment and the same `B_AGC` setting, the simulation should be reproducible apart from possible small numerical differences among software/platform versions.
